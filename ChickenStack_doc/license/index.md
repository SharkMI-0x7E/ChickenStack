## 什么是 MIT License？ {#what-is-mit}

::: tip 简单来说
MIT License 是一种非常宽松的开源许可证，它给予使用者最大的自由度，同时只要求保留版权声明。
:::

MIT License 是世界上最流行的开源许可证之一，被广泛用于各种开源项目，包括：

- 📦 Node.js
- 🎨 Vue.js
- ⚡ Vite
- 🚀 React
- 📝 VSCode

## 你可以做什么？ {#what-you-can-do}

使用 MIT License 的软件，你可以：

### ✅ 完全自由

- 🎯 **自由使用**：用于个人或商业项目
- 🔧 **自由修改**：根据需要修改代码
- 📤 **自由分发**：分享给其他人
- 💰 **商业用途**：用于商业产品
- 🔗 **混合使用**：与专有软件一起使用

### 📋 示例场景

```bash
# 商业项目中使用
$ npm install chickenstack

# 修改代码并发布
$ git clone https://github.com/SharkMI-0x7E/ChickenStack.git
$ cd ChickenStack
# 修改代码...
$ npm publish my-chickenstack

# 在专有软件中使用
$ npm install chickenstack
# 在你的专有软件中引用
```

## 你需要遵守什么？ {#what-you-must-do}

虽然 MIT License 非常宽松，但你必须遵守以下两个条件：

### ⚠️ 必须包含版权声明

在任何分发或修改的版本中，必须包含原始的版权声明：

```text
Copyright (c) 2025-Present ChickenStack Contributors
```

### ⚠️ 必须包含许可证声明

必须在所有副本中包含完整的 MIT License 文本：

```text
Permission is hereby granted, free of charge, to any person obtaining a copy
of this software and associated documentation files (the "Software"), to deal
in the Software without restriction, including without limitation the rights
to use, copy, modify, merge, publish, distribute, sublicense, and/or sell
copies of the Software, and to permit persons to whom the Software is
furnished to do so, subject to the following conditions:
...
```

## 为什么选择 MIT License？ {#why-mit}

### 🎯 优点

| 优点 | 说明 |
|------|------|
| 🚀 **简单明了**：文本短小，易于理解 |
| 🌍 **广泛接受**：被广泛使用和认可 |
| 🔓 **最大自由**：给予使用者最大的自由度 |
| 💼 **商业友好**：允许商业使用 |
| 📝 **易于遵守**：只有两个简单的条件 |

### 🤝 对贡献者友好

MIT License 对贡献者也很友好：

- ✅ 保护作者的版权
- ✅ 要求保留许可证声明
- ✅ 不限制代码的使用和分发
- ✅ 鼓励社区参与和贡献

## 常见问题 {#faq}

### Q: 我可以用 MIT License 的代码赚钱吗？

**A**: 可以！MIT License 允许商业用途，你可以将代码用于商业产品并盈利。

### Q: 我需要公开我的修改吗？

**A**: 不需要。MIT License 不要求你公开修改后的代码。

### Q: 我可以更改许可证吗？

**A**: 可以，但只能在新文件中更改。原始文件必须保持 MIT License。

### Q: 我可以删除版权声明吗？

**A**: 不可以。MIT License 要求在所有副本中保留版权声明。

### Q: MIT License 和 GPL 有什么区别？

**A**: MIT License 更宽松，允许闭源；GPL 要求开源修改后的代码（传染性）。
